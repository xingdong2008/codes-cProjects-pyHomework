# 课程作业合集 / Course Homework Collection

本仓库收录了 C 语言和 Python 相关的课程作业源码与实验报告，文件已整理为中文 / 英文双语形式。
This repository collects C and Python course homework source code and lab reports, organized in a bilingual (Chinese / English) format.

## 目录结构 / Directory Structure

- `cHomework/` — C 语言程序源码 / C programming source code
- `pyHomework/` — Python 课程实验报告（Markdown）/ Python course lab reports (Markdown)

## 说明 / Notes

- 所有代码保留原始逻辑，仅补充了中英双语注释。/ All code keeps its original logic; only bilingual comments were added.
- 报告内容为中英双语对照。/ The reports are presented in bilingual Chinese-English form.
- 已移除作者姓名、学号等个人信息。/ Author names and student IDs have been removed.
