### 案例二：AI 生成新年祝福程序 / Case 2: AI-Generated New Year Greeting

**1. 初始意图与 Prompt / Initial Intent & Prompt**

- **初始意图 / Initial Intent**：设计一个 Python 程序，输入姓名和年份，生成“xxx 新年快乐！欢迎来到 xxx 年”，要求过滤掉非法输入（如名字夹杂数字、年份包含字母等），并循环提示重新输入。
  / Design a Python program that takes a name and a year, generates "xxx Happy New Year! Welcome to xxx", filters invalid input (e.g., a name containing digits or a year containing letters), and keeps prompting until the input is valid.
- **Prompt（未应用 RTCO 原则）/ Prompt (RTCO Principle Not Applied)**：
  - Role（角色）/ Role：缺失。/ Missing.
  - Task（任务）/ Task：编写一个循环判断的新年祝福脚本。/ Write a New Year greeting script with loop-based validation.
  - Constrain（限制）/ Constrain：需要严格校验格式，名字必须是纯字母（含中文），年份必须是纯数字。/ Strictly validate the format: the name must contain only letters (including Chinese), and the year must contain only digits.
  - Output（输出）/ Output：缺失。/ Missing.

**2. 翻车现场与错误定位 / The Failure & Error Location**

- **错误代码与现象 / Erroneous Code & Symptom**：AI 给出了代码，使用了 `name.isalpha()` 和 `year.isdigit()` 判断。/ The AI used `name.isalpha()` and `year.isdigit()` for validation.
- **翻车现象 1 / Symptom 1**：当输入名字为 "Tony10" 或年份为 "342342kkk" 时确实被拦截了。但当输入年份为 "3214" 或 "99999" 时，程序直接生成“欢迎来到 3214 年”，产生了逻辑 Bug，不符合常理。同时，若直接输入空字符串，程序会不断空转。
  / Inputs like "Tony10" or "342342kkk" were indeed blocked, but entering years like "3214" or "99999" still printed "Welcome to 3214", which is illogical. Also, an empty string made the program loop endlessly.
- **翻车现象 2 / Symptom 2**：当输入名字为空时，输入验证逻辑稍有疏忽就会跳过。
  / With an empty name, a small oversight in validation let it slip through.
- **错误类型 / Error Type**：**边界遗漏 / 逻辑不全 / Missing boundary checks / incomplete logic**。AI 完成了基础语法校验，但缺乏业务逻辑范围限制。AI 在后续的说明中也自己提出了“优化建议：年份范围没有做限制”。
  / The AI handled basic syntax validation but lacked business-rule range checks. Later, the AI itself suggested: "the year range is not restricted."

**3. 多轮对话修复与收获 / Multi-turn Fix & Takeaways**

- **追问指令 / Follow-up Instruction**：我向 AI 提问：“当前的代码没有限制年份的合理区间（如 1900-2100），且容易造成空值陷入死循环。请加入年份范围校验，并优化循环退出逻辑。”
  / I asked the AI: "The current code doesn't restrict the year to a sensible range (e.g., 1900-2100) and can get stuck in an infinite loop on empty input. Please add a year range check and improve the loop-exit logic."
- **最终修复代码 / Final Fixed Code**：

```python
while True:
    name = input("请输入姓名: ").strip()
    year = input("请输入年份: ").strip()
    
    if not name.isalpha() or not year.isdigit():
        print("请重新输入")
        continue
        
    year_int = int(year)
    if not (1900 <= year_int <= 2100):  # 边界修复 / boundary fix
        print("请重新输入")
        continue
        
    print(f"{name}新年快乐！欢迎来到{year_int}年")
    break
```

- **最终收获 / Key Takeaway**：AI 不是万能的，它不会考虑现实业务需要，也不管现实是否存在这样的解，程序员应该做到督查 AI 的作用，确保代码能够有足够的现实意义和包容性。
  / AI is not all-powerful: it doesn't consider real-world business needs or whether a solution actually makes sense. Programmers must supervise AI to ensure the code is meaningful and robust.
