### 案例三：判断闰年逻辑 / Case 3: Leap Year Logic

**1. 初始意图与 Prompt / Initial Intent & Prompt**

- **初始意图 / Initial Intent**：让 AI 写一个判断闰年的程序。规则是：能被 4 整除但不能被 100 整除，或者能被 400 整除。
  / Ask the AI to write a leap-year checker. The rule: divisible by 4 but not by 100, or divisible by 400.
- **Prompt（应用了 RTCO 原则）/ Prompt (RTCO Principle Applied)**：
  - Role（角色）/ Role：你是 Python 初级开发工程师。/ You are a junior Python developer.
  - Task（任务）/ Task：用 Python 写一个判断输入年份是否为闰年的程序。/ Write a Python program that checks whether an input year is a leap year.
  - Context（背景）/ Context：严格按照闰年计算规则：能被 4 整除且不能被 100 整除，或者能被 400 整除。/ Strictly follow the leap-year rule: divisible by 4 and not by 100, or divisible by 400.
  - Output（输出）/ Output：输出代码即可。/ Output the code only.

**2. 翻车现场与错误定位 / The Failure & Error Location**

- **错误代码与现象 / Erroneous Code & Symptom**：AI 给出了代码，但逻辑写错。/ The AI produced code, but the logic was wrong.

```python
    # AI 错误代码 / AI's incorrect code
    if year % 4 == 0 or year % 400 == 0 and year % 100 != 0:
```

- **翻车现象 / Symptom**：输入 1900。按照逻辑，`1900 % 4 == 0` 为 True，or 后面的语句因为 and 优先级高，`1900 % 400 == 0` 为 False，所以整体为 True。程序输出“1900 是闰年”。
  / With input 1900, `1900 % 4 == 0` is True; because `and` has higher precedence, `1900 % 400 == 0` is False, so the whole condition is True. The program printed "1900 is a leap year".
- **错误类型 / Error Type**：**逻辑 Bug（优先级错误）/ Logic bug (operator precedence error)**。AI 未能正确理解数学逻辑表达中的短路和优先级问题。
  / The AI failed to understand short-circuit evaluation and precedence in the logical expression.

**3. 多轮对话修复与收获 / Multi-turn Fix & Takeaways**

- **追问指令 / Follow-up Instruction**：代码逻辑有漏洞！输入 1900 年输出了“是闰年”，但 1900 年不是闰年。请注意运算符的优先级，用括号明确范围。请修正。
  / The logic has a flaw! Entering 1900 prints "is a leap year", but 1900 is not a leap year. Please mind operator precedence and use parentheses to make the scope explicit, then fix it.
- **最终修复代码 / Final Fixed Code**：

```python
year = int(input("请输入年份: "))
if (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0):
    print(f"{year} 是闰年")
else:
    print(f"{year} 不是闰年")
```

- **核心收获 / Key Takeaway**：对 AI 生成的复杂条件判断，必须人为代入边界值进行验证。AI 在逻辑嵌套上极易出现幻觉。
  / For complex conditional logic generated by AI, always verify it manually with boundary values. AI easily hallucinates with nested logic.
